The interface uses Noto Sans Arabic for Arabic text and Inter for Latin text and digits.
Both are variable WOFF2 fonts, hosted with the application and licensed under the
SIL Open Font License. Copyright and license notices are in the adjacent OFL files.

Sources: [Google Fonts](https://fonts.google.com/),
[Inter](https://github.com/google/fonts/tree/main/ofl/inter), and
[Noto Sans Arabic](https://github.com/google/fonts/tree/main/ofl/notosansarabic).

`fonts.css` contains the original subset ranges and weight declarations. Only the
Arabic, Latin and extended Latin subsets are included. Text uses weights 400–700.
